## ❓ About

**AeroBlender** is a library mod based on **TerraBlender**, specifically designed to bring its biome handling capabilities into **The Aether** dimension. 

* It provides an API that allows developers to add custom biomes in a simple, compatible way with The Aether.
* It is the core for many Aether addons, including *Deep Aether* and *The Aether: Redux*.

---

## ❓ How do I use it?

Aeroblender is used exactly like Terrablender, but be sure to use "AetherRegionType.THE_AETHER" in the definition of your mod's region.

---

## 📋 Requirements

Make sure you have the following dependencies:

* [**The Aether**](https://modrinth.com/mod/aether)
* [**TerraBlender**](https://modrinth.com/mod/terrablender)
